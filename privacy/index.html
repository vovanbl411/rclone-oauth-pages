Privacy Policy

This is a personal-use integration for backing up encrypted KeePassXC database copies to Google Drive using rclone.

Google user data

The integration accesses Google Drive using the drive.file scope. It uses this access to upload, read, and manage backup files created through this integration.

Storage and sharing

OAuth credentials and tokens are stored locally by rclone on the owner's device. There is no separate backend service or application database.

Google user data is not sold or shared with third parties. Backup files remain in the owner's Google Drive until the owner removes them.

Revoking access

OAuth access can be revoked through Google Account security settings or by deleting or reconfiguring the rclone OAuth configuration.
